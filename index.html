How to format names One name per line: 
Emily Carter
  James Miller
  Sophia Reed
You can also separate them with commas or semicolons: 
Emily Carter, James Miller, Sophia Reed
Numbered lists (1. Emily, 2) James, - Sophia) work too: numbers and dashes are removed automatically. A .txt or .csv file uses the same format: names only, no headers.
